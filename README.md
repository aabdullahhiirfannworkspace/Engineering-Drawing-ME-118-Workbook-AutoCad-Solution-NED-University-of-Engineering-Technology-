# Engineering Drawing ME-118 Workbook AutoCad Solution NED University of Engineering Technology

## Overview

This repository contains AutoCAD solutions for the **Engineering Drawing (ME-118) Workbook** used at **NED University of Engineering & Technology**. It is intended as a study resource to help students understand engineering drawing concepts, practice AutoCAD drafting techniques, and compare their work with completed solutions.

## Contents

* AutoCAD drawing files for workbook exercises
* Practice solutions for selected ME-118 problems
* Reference material for learning engineering drawing

## Purpose

The materials are provided for educational purposes only. Students are encouraged to attempt each exercise independently before referring to the solutions.

## Requirements

* AutoCAD (or another compatible DWG viewer/editor)

## Disclaimer
*Error and omissions excepted
These solutions are shared to support learning and should not be submitted as original coursework. Please follow your instructor's academic integrity guidelines.
